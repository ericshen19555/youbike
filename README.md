# 🚲 YouBike Guard: 全方位監控系統

YouBike Guard 是一個專為 YouBike 使用者設計的智慧監控系統，旨在解決「熱門站點無車可用」或「無位可還」的痛點。本專案透過自動化監控與 Telegram 機器人，提供精準、即時的資訊與提醒。

---

## 🏗️ 系統架構 (System Architecture)

專案採用 **3 層式非同步架構**，確保高效能與擴展性：

1.  **Layer 1: RRule Scheduler (排程層)**
    - 監控所有使用者訂閱的週期規則（RRule/ONCE）。
    - 在提醒時間前 20 分鐘（預設）自動派發高頻監控任務。
2.  **Layer 2: Monitor Engine (監控層)**
    - 針對已啟動的任務進行即時輪詢。
    - **動態頻率**：根據車輛剩餘數自動調整檢查間隔（15s, 30s, 60s），在車位即將用罄時提供最即時的情報。
3.  **Layer 3: Telegram Bot (互動層)**
    - 提供直覺的 UI 與 NLP 指令處理。
    - 整合地理資訊搜尋與多輪對話機制。

## 🌟 核心功能說明 (Core Features)

### 1. 📍 智慧找點與定位
- **座標搜尋**：傳送手機位置座標，系統立即回傳最近 5 個站點及其距離。
- **模糊匹配**：輸入「科技」即可找到「科技大樓站」。若有歧義，系統會提供編號讓使用者選號。
- **持續搜尋**：在選擇編號時可隨時改輸新關鍵字，系統會自動切換搜尋而不遺失原本的參數。

### 2. ⏰ 彈性監控規則
- **循環提醒**：支援「每天 08:30」、「週一至五 18:00」等規則（透過 RRule 實作）。
- **單次提醒**：直接輸入 `/add 站點名` 若無時間，預設為「30 分鐘後一次性提醒」，出門前隨手設定超方便。
- **車型細分**：可指定監控「2.0 普通車」、「2.0E 電輔車」或兩者皆可。

### 3. 🔍 深度資訊查詢
- **`/query` 指令**：提供站點完整資料，包含區域、詳細地址，以及最關鍵的 **2.0/2.0E 分類數量**。
- **實時快取**：所有數據皆與 YouBike 官方 API 保持同步，並透過本地資料庫快取加速查詢。

## 🔧 技術亮點 (Technical Highlights)

- **Station Metadata Persistence**：將全台 1400+ 站點資訊持久化於 SQLite，搜尋速度提升 100 倍以上，且具備斷網運作能力。
- **自動化測試套件**：擁有 **177 個測試案例**，達成 **99% 程式碼覆蓋率**，確保在修改核心功能時系統依然穩健。
- **資料庫遷移系統**：內建自動架構升級邏輯，支援從單一訂閱平滑過渡至多時段訂閱模式。
- **NLP Parser**：口語化解析引擎，讓使用者不需要學習複雜的 JSON 或指令格式。

## 📖 快速上手 (Quick Start)

### 常用指令
- `/start` - 顯示歡迎訊息與說明。
- `/add 站點 門檻 [時間]` - 新增監控。例：`/add 科技大樓 3 每天 08:30`
- `/query 站點` - 查詢站點即時詳細資訊。
- `/list` - 查看我的所有監控清單。
- `/remove 站點` - 移除特定站點的監控。
- `/cancel` - 取消目前的選擇動作。

### 專案啟動
```bash
# 安裝依賴
pip install -r requirements.txt

# 設定環境變數 (.env)
TELEGRAM_BOT_TOKEN=你的Token
TELEGRAM_CHAT_ID=你的ID

# 啟動主程式
python main.py
```
